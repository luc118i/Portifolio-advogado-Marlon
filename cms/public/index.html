PostgreSQL · Neon

Banco de dados

Os posts publicados ficam armazenados no Neon — banco PostgreSQL em nuvem, gratuito e sem suspensão por inatividade. Execute cms/db/schema.sql no SQL Editor antes de usar.

→ Criar projeto gratuito em console.neon.tech

Neon Dashboard → Connection Details → Pooled connection.

Meta Graph API

Instagram

Exibe os posts publicados do perfil Instagram do cliente dentro do CMS. Requer conta Business ou Creator.

→ Obter token no Graph API Explorer (scope: instagram_basic)

Use um Long-lived token (válido por 60 dias). Renove na aba Posts → Instagram.

Necessários apenas para converter token de curta duração em long-lived.
